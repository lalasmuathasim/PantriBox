# Product Foundation Overview

STATUS: ACTIVE

## Objective

Establish a production-oriented monorepo foundation for PantriBox without implementing full product functionality.

## Included in this bootstrap

- Mobile app architecture and navigation shell
- Backend service and API foundation
- Initial domain model scaffolding
- Documentation, ADRs, specs, PRPs, CI, Docker, and agent guidance
- MCP-oriented architectural boundary

## Explicitly excluded

- Full CRUD implementations
- Real authentication providers
- Receipt OCR integrations
- Product normalization pipelines
- Shopping optimization algorithms
- Nutrition analysis
