# Mobile Design Refresh Overview

STATUS: ACTIVE

## Objective

Refine the PantriBox mobile visual system so the application feels polished, premium, and native on iOS and Android while preserving existing functionality and architecture.

## Motivation

The current bootstrap UI proves structure and navigation, but the styling is intentionally minimal. PantriBox now needs a stronger mobile design language with better hierarchy, spacing, card treatment, navigation polish, and reusable screen patterns.

## In scope

- Centralized light-theme redesign through the existing mobile theme layer
- Reusable design tokens and shared UI components
- Reversible theme architecture that preserves the current styling path
- Visual updates to the existing placeholder screens:
  - Onboarding
  - Sign In
  - Sign Up
  - Home
  - Shopping Lists
  - Shopping List Detail
  - Create Shopping List
  - Scan Receipt
  - Insights
  - Profile
- Native-feeling bottom navigation and shared page scaffolding
- Improved form styling and card hierarchy

## Out of scope

- New product capabilities
- Backend or API changes
- Navigation or domain logic changes
- Full dark-mode redesign
- New font dependencies
- Real analytics, receipt capture, or optimization implementations

## Design intent

- Soft warm-neutral background
- Large white surfaces with restrained elevation
- Rounded, contemporary geometry
- Strong metric hierarchy for shopping insights
- Minimal but clear status and progress elements
- Shared PantriBox visual identity that still respects platform conventions
