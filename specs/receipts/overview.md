# Receipts Spec

STATUS: PLANNED

Future work will define receipt capture, upload, extraction, parsing, review, correction, and purchase confirmation flows.

## Implemented Data Foundation

Receipt records retain household ownership, uploader, protected storage
reference, raw OCR text, capture timestamp, capture source, extraction status,
provider, and confidence. Raw receipt images are never exposed through this
foundation. Upload, OCR, parsing, and review services remain planned.
